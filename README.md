# COWBOY — ไฟล์ติดตั้งแอป Android

ที่เก็บไฟล์ติดตั้ง (APK) ของแอป **COWBOY** ระบบจัดการงานงดจ่ายกระแสไฟฟ้า
เก็บไว้ที่นี่เพื่อให้แอปในมือถือของทีมดาวน์โหลดอัปเดตเองได้

- ไฟล์ติดตั้งอยู่ในหน้า [Releases](../../releases) — ดาวน์โหลดไฟล์ `.apk` ของรุ่นล่าสุด
- ที่เก็บนี้มีเฉพาะไฟล์ติดตั้ง **ไม่มีซอร์สโค้ดและไม่มีข้อมูลของงานหรือลูกค้า**
- การเข้าใช้งานแอปต้องเข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลระบบสร้างให้เท่านั้น

แอปจะตรวจลายนิ้วมือไฟล์ (SHA-256) ก่อนติดตั้งทุกครั้ง
